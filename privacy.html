Privacy Policy — Fika

Last updated: 10 October 2026

Fika ("the application") is a private, single-user personal assistant tool operated on a private server by and for one individual — the owner of the Google Account it is connected to ("the owner"). This policy explains what data the application accesses, why, how it is stored, and how it is deleted.

1. Who uses this application

The application has exactly one user: the owner. There is no registration, no third-party access, no multi-tenant service, and no commercial offering. The application is not distributed or made available to the public.

2. Google user data the application accesses

With the owner's explicit consent, through Google's official APIs, the application may access the following data belonging only to the owner's own Google Account:

  • Gmail — read, search, label and send email on the owner's behalf (e.g. filing invoices, drafting supplier correspondence). Scope: gmail.readonly, gmail.modify, gmail.send.
  • Google Calendar — read and create calendar events and reminders for the owner. Scope: calendar.
  • Google Drive — store and retrieve the owner's own files (e.g. a mirror of the owner's photo/document library). Scope: drive.
  • Google Sheets and Docs — read and update the owner's own spreadsheets and documents used for personal records. Scope: spreadsheets, documents.
  • Contacts (read-only) — resolve the names of people the owner already corresponds with. Scope: contacts.readonly.

The application does not request or access any other Google user data, and it never accesses data belonging to any Google Account other than the owner's own.

3. How the data is used

Data is used solely to perform tasks the owner asks for, on the owner's own behalf and on the owner's own instruction. Examples: summarising the owner's unread email, creating a calendar reminder, storing a receipt image, or looking up a contact's name. There is no profiling, no advertising, no marketing, and no automated decision-making about any other person.

4. Storage, sharing and disclosure

  • Storage. Data is processed and stored on a private, single-tenant server controlled by the owner. Access is restricted to the owner.
  • No selling or sharing. Google user data is never sold, rented, traded, or transferred to any third party.
  • No advertising. Google user data is never used for advertising, ad targeting, or audience segmentation.
  • No human review. Google user data is not read by any human other than the owner.
  • Limited processors. When the owner explicitly asks for a task that requires it, the application may forward a minimal snippet of text to an AI language-model provider (e.g. DeepSeek or Google Gemini) strictly to produce that answer. No bulk mailbox data is transferred, no data is used to train third-party models, and nothing is forwarded without an explicit owner instruction.
  • Legal. Data may be disclosed only if required by applicable law.

5. Security

Connections are made over HTTPS/TLS via Google's official API endpoints. OAuth credentials and access tokens are stored in protected files on the owner's private server and are never shared or embedded in public code. Access can be revoked by the owner at any time from the Google Account permissions page (myaccount.google.com/permissions).

6. Retention and deletion

  • Data is retained only as long as it is useful for the owner's records, or until the owner asks for it to be deleted.
  • The owner can request deletion of any or all stored data at any time by email; stored copies are removed promptly (within 30 days).
  • Revoking the application's access in the Google Account permissions page immediately stops all further access.

7. Limited Use disclosure

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Children

The application is not directed to children and is not used by anyone other than the owner.

9. Changes

Any future change to this policy will be published on this page with an updated date.
